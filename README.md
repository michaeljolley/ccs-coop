# Build Apps with GitHub Copilot

A 9-week, hands-on course that takes high school students from zero experience to shipping real web apps, using the GitHub Copilot CLI as their building partner.

This repository is the course website, served with GitHub Pages.

## What students build

Each week pairs one concept with one thing they build:

| Week | Concept | Build |
| ---- | ------- | ----- |
| 1 | What is an LLM? | A playable game of their choice |
| 2 | Prompting and context | Polish the game and deploy it to GitHub Pages |
| 3 | Hallucinations | A Pomodoro study timer with stats |
| 4 | AI agents | Finish and extend the study timer |
| 5 | Model Context Protocol (MCP) | A weather dashboard using a live API |
| 6 | Skills | Add features and polish the dashboard |
| 7 | Hooks | A budget and expense tracker with charts |
| 8 | The full ecosystem | Finish and polish the tracker |
| 9 | Ethics and what's next | A wildcard project of their choosing |

## Structure

- `index.html` is the course landing page.
- `lessons/` holds the pre-course setup guide and all nine weekly lessons as self-contained HTML.
- `reference/` holds the prompting cheat sheet and glossary.
- `assets/` holds the shared stylesheet and quiz widget.

## Running locally

Every page is plain static HTML. Open `index.html` in a browser, or serve the folder with any static file server.

## Built with

The GitHub Copilot CLI. The course teaches the same tool it was built with.
