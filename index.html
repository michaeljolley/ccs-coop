Build Apps with GitHub Copilot

A 9-week, hands-on course for high school students. No experience needed. You'll go from zero to shipping real web apps that live on the internet, using the GitHub Copilot CLI as your building partner.

Start here

Before your first class, get your laptop set up. It takes about 20 minutes.

Pre-Course Setup: Get Ready to Build Create a GitHub account, install the Copilot CLI, and confirm everything works. Do this before Week 1.

Prefer one page? See the Getting Started guide (requirements and setup together), or download the requirements PDF to print or share.

The 9 weeks

Each week pairs one concept with one thing you build. Roughly 30 minutes learning, 30 minutes building.

  • Week 1 What is an LLM? + Build a Game Learn what a large language model actually does, then build a playable game of your choice with Copilot.
  • Week 2 Prompting & Context + Deploy Your Game See how prompts and context steer the output, then polish your game and put it live on GitHub Pages.
  • Week 3 Hallucinations + Build a Study Timer Understand why AI is sometimes confidently wrong, then build a Pomodoro study timer with stats.
  • Week 4 Agents + Finish Your Study Timer Learn what an AI agent is and how it differs from chat, then extend and finish your timer.
  • Week 5 MCP + Build a Weather Dashboard Meet the Model Context Protocol, then build a dashboard that pulls real weather data from an API.
  • Week 6 Skills + Finish Weather Dashboard Learn how skills give AI reusable capabilities, then add features and polish your dashboard.
  • Week 7 Hooks + Build a Budget Tracker Understand event-driven hooks, then build a budget and expense tracker with charts.
  • Week 8 The Full Ecosystem + Finish Budget Tracker See how LLMs, agents, MCP, skills, and hooks fit together, then finish and polish your tracker.
  • Week 9 Ethics & What's Next + Wildcard Project Talk through responsible AI use and where to go next, then build anything you want.
