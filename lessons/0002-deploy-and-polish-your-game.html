Part 1: Prompting & Context (~30 minutes)

What happened last week?

Some of you wrote a short prompt and got a decent game. Others wrote a longer prompt and got something even better. A few got something weird. Why? The answer is context.

The Context Window

Remember: an LLM predicts what comes next. But next after what? The "what" is called the context window: it's everything the model can "see" when making predictions.

  • Your prompt is part of the context
  • The current file you have open is part of the context
  • Previous messages in the chat are part of the context
  • The context window has a limit: the model can only hold so much at once
💡 Analogy Imagine asking a friend to help you with homework, but they can only see the last 2 pages of your notebook. If the important info is on page 1, they can't use it. That's what a context window limit feels like to an LLM.

Why Prompting Matters

Your prompt is the steering wheel. A vague prompt gives the LLM too many possible "next words" to predict, so it picks something generic. A specific prompt narrows the possibilities down to what you actually want.

Prompt Engineering Patterns

Pattern When to use Example
Be specific Always "3x3 grid with X and O" not "a board game"
Give examples When you want a specific format "Format like: Player X wins! 🎉"
Describe constraints When you want to limit the output "Single HTML file, no external libraries"
Iterate, don't restart When output is close but not right "Good, but make the grid bigger and add hover effects"

Context in practice

When you stay in the same Copilot session, earlier messages are still in context, so the model "remembers" what you built. When you close Copilot and start a fresh session, it forgets the conversation (though it can still read your files). This is why iterating in the same session works smoothly.

What is the "context window" in an LLM?

The terminal window where you type The amount of time the model takes to respond All the text the model can see when making predictions The browser window where your app runs

Why does a more specific prompt produce better results?

It narrows the possible predictions to what you want The LLM tries harder when it detects more words Specific prompts unlock a premium mode in Copilot It forces the model to search the internet first

Part 2: Polish & Deploy (~30 minutes)

Now apply what you just learned. You'll use better prompting to improve your game, then put it live on the internet.

Improve with better prompts (15 min)

Open your terminal, navigate to your game folder, and start Copilot:

cd ~/Documents/my-game
copilot

Using what you now know about context and prompting, ask for a specific improvement. Notice how referencing what already exists uses context effectively:

In my index.html, the game works but the win detection doesn't check 
diagonal lines. Also add a hover effect on empty squares and make the 
overall layout centered on the page with a max-width of 500px.

The Copilot CLI reads your files as context, so it already knows what's in index.html without you pasting it. You can also @-mention a file to point Copilot at it directly.

Deploy to GitHub Pages (15 min)

Here's the magic of the Copilot CLI: it can run commands for you. You don't need to memorize git commands. Just ask. In your Copilot session, type:

Deploy this project to GitHub Pages. Create a new public repository 
called my-game, push my code, enable GitHub Pages, and tell me the URL.

Copilot will show you the commands it wants to run (git init, commit, create the repo, enable Pages) and ask for your approval before each step. Read what it's doing, approve, and watch it work.

⚠️ If something goes wrong If a step fails, Copilot usually explains the error and tries a fix. If it gets stuck, tell it what you see: "That gave an error saying [paste]. What now?" This is the same iteration loop; the error message is context that helps Copilot predict the fix.

After a minute, visit your live URL: https://yourusername.github.io/my-game/

🎯 Today's Win Share your live game URL with a classmate or text it to a friend. You built this. It's on the internet. That's real.
