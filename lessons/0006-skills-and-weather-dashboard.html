Part 1: Skills (~30 minutes)

The building blocks problem

You've now built three apps. Each time, you had to describe what you wanted from scratch. What if you could teach Copilot a reusable capability, something it can do over and over without you re-explaining it?

That's what a skill is.

What is a skill?

A skill is a packaged set of instructions that gives an AI agent a specific capability. Think of it as a recipe card you hand to a chef:

  • "Here's how to deploy to GitHub Pages" → a deployment skill
  • "Here's how to write unit tests for JavaScript" → a testing skill
  • "Here's how to create responsive CSS layouts" → a styling skill
  • "Here's how to review code for accessibility" → a review skill
💡 Analogy Skills are like apps on your phone. Your phone (the AI) can do basic things on its own, but each app (skill) gives it a specific new capability. You don't rebuild the camera app every time you take a photo. You just open it.

Skills in the Copilot ecosystem

In GitHub Copilot, skills can:

  • Provide specialized knowledge: like knowing your project's coding standards
  • Follow specific workflows: like always running tests after making changes
  • Use specific tools: like knowing how to call a particular API
  • Be shared: a skill that works for you can work for your whole team

Part 2: Polish Your Weather Dashboard (~30 minutes)

Use this session to level up your weather app, and notice how you're building your own skills as a developer. Each pattern you learn (fetch data, handle errors, render results) is reusable across future projects.

Feature ideas: pick 1-2

  • Multiple cities: Save favorite cities and switch between them
  • Unit toggle: Switch between °C and °F
  • Hourly forecast: Show hour-by-hour for today
  • Weather backgrounds: Change the page background based on conditions (sunny = yellow, rainy = grey)
  • "Use my location" button: Auto-detect city using browser geolocation

Practice the skill mindset

As you build, notice patterns you're reusing:

  • Fetching data from an API → you did this last week
  • Saving to localStorage → you did this with the timer
  • Handling user input → you did this with the game

You are accumulating skills. Each project makes the next one faster.

Deploy

Ask Copilot to deploy it for you, just like you did with your game:

Deploy this to GitHub Pages. Create a public repo called weather-app, 
push the code, enable Pages, and give me the URL.

Between Sessions

  • Think about reuse: What patterns from your weather app could you reuse in a future project? (Hint: fetching data, displaying lists, error handling)
  • Explore: Look at MCP servers on GitHub: browse what tools people are building for AI. You don't need to install anything, just explore.
