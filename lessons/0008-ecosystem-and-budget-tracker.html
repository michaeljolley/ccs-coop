Part 1: Putting It All Together (~30 minutes)

The full picture

Over the past 7 weeks, you've learned five key concepts. Today we connect them into one mental model.

You (the human, the one with the goal)
  ↓ gives instructions to
Agent (an LLM that can take actions in a loop)
  ↓ uses its brain:
LLM / Model (predicts text, reasons about code)
  ↓ connects to the world via:
MCP (universal adapter to external tools & data)
  ↓ knows how to do specific things via:
Skills (packaged capabilities and instructions)
  ↓ reacts to events automatically via:
Hooks (triggers that fire when something happens)

A real-world scenario

Let's trace how all these work together in a real workflow:

You tell the Copilot agent: "Add a dark mode to my budget tracker."

The agent's LLM reads your code (context) and predicts what CSS changes to make.

It uses a skill that knows your project's coding standards and design patterns.

It connects via MCP to a tool that runs your code in a preview browser to check if it looks right.

A hook automatically runs when it saves the file, formatting the code and checking for errors.

You review and approve. Done.
